🔧 Usage in Game Engines

Unity Integration:

1. Import PNG tiles from tiles/ folder

2. Load metadata.json for world coordinates

3. Use road_network.json for AI pathfinding

4. Each tile = 1.28km × 1.28km (256 cells × 5m each)

Godot Integration:

1. Create TileSet resource from PNG tiles

2. Parse tilemap.csv for procedural generation

3. Import grid_uint8.npy using NumPy-compatible tools

Custom Engine Integration:

1. Load tiles on-demand based on player position

2. Use 5m cell resolution for collision detection

3. Implement streaming system for performance

4. Place procedural assets on appropriate terrain types
