# 🔧 Utilities

This folder contains development utilities and source data generation scripts.

## Scripts

### `Staten_island.py`
- Downloads fresh OpenStreetMap data for Staten Island
- Recreates source GeoJSON files
- Use when you want to update with latest OSM data

### `fast_topographic_tiles.py` 
- Alternative tile generation with optimized processing
- Development/testing utility for different tile creation approaches

## Usage

These scripts are for advanced users who want to:
- Generate maps from scratch
- Update source data
- Experiment with different processing approaches

For normal map usage, see the main README.md and use the pre-generated map files.
